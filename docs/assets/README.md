# Documentation assets

Visual assets used by the public documentation and the portfolio README.

## Dashboard screenshots

Drop the screenshots in this directory using these exact file names:

| File | View |
| --- | --- |
| `dashboard-today.png` | **Today** tab: daily status, ACWR and quick stats. |
| `dashboard-trends.png` | **Trends** tab: fitness, fatigue, freshness and decoupling. |
| `dashboard-tapering.png` | **Plan → Tapering simulator** with a visible projection. |
| `dashboard-race-taper.png` | **Plan → Race taper** with a generated plan. |
| `dashboard-race-predictor.png` | **Plan → Race predictor** with a visible prediction. |

## Capture guidelines

- PNG format, dark theme, browser chrome hidden.
- Consistent width and zoom across screenshots; 1920×1080 or 1440×900 preferred.
- No names, tokens, credentials or other directly identifying information.
- Review the images for personal biometric data before publishing (`RNF-01`).
- Remove EXIF/metadata when possible.

The README uses `docs/assets/dashboard-today.png` as the hero image and the remaining
captures in the dashboard tour. Missing screenshots must be replaced before the public
release is tagged.
